# Agent workflow — Lab 3

Baseline каркас подготовлен с разделением ответственности:

- LLM: смысловая генерация структурированного черновика;
- Pydantic: структурная валидация;
- Python tools: стоимость, КБЖУ и формальные ограничения;
- API: транспорт и контролируемые ошибки;
- tracing: наблюдаемость каждого LLM-вызова;
- eval runner: воспроизводимый прогон Golden Dataset.

Перед merge человек должен проверить сгенерированный код, особенно модель, OpenAPI-контракт, обработку ошибок и отсутствие секретов.
