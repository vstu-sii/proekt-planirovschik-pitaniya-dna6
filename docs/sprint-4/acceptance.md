## 0. Definition of Done (DoD)

- [ ] PRD и Use Cases обновлены.
- [ ] Сценарий проходит E2E на проде.
- [ ] Нет открытых P0 по принятой фиче.
- [ ] Quality-gate зеленый.
- [ ] Safety-тесты пройдены, критические нарушения отсутствуют.
- [ ] Лимиты и деградация проверены.
- [ ] Все отклонения заведены в бэклог с ID, приоритетом и владельцем.
- [ ] Публичный URL заполнен в README, режим провайдера на проде подтвержден сквозным прогоном.
- [ ] Machine-readable коды причин различают нарушение ограничений, некорректный запрос и технический сбой.
- [ ] Контракт `totals` согласован: стоимость покупки, КБЖУ плана, дневные показатели – отдельно.
