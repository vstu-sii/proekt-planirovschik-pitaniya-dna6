## Что это значит для приемки

- Нельзя утверждать «модель соблюдает аллергены»: `allergen_compliance=null`, safety не подтверждена. [eval-report §6]
- Нельзя утверждать «UI работает на мобильном»: устройство не запускалось, проверены только исходники (см. NT-16).
- Нельзя считать latency p95 15,2794 с SLA для всех запросов: только для 13 полученных ответов. [eval-report §6]
- Нельзя считать POST-1/POST-2/POST-3 выполненными: меню не отображается полностью, список покупок недоступен, стоимость не проверена. [bug-list: BUG-023, BUG-024, BUG-026]
- Нельзя считать UC-4…UC-7 проверенными: они не реализованы. UC-8 и UC-9 вне скоупа MVP (Спринт 5+). [01-summary: карта покрытия]
