# Архитектура системы

Архитектура хранится в репозитории как код на PlantUML с использованием нотации C4.

- [`context.puml`](context.puml) — контекст системы: пользователь и внешние системы;
- [`container.puml`](container.puml) — мобильный клиент, backend и база данных;
- [`../adr/adr-04-modular-monolith.md`](../adr/adr-04-modular-monolith.md) — принятое архитектурное решение.

Проверка контейнерной модели:

```bash
npm ci
npm run architecture:check
```

Ожидаемый результат — `0 violations`, код возврата `0`.

## Границы ответственности

- мобильное приложение отвечает только за ввод и отображение данных;
- FastAPI проверяет запросы, управляет планами и оркестрирует AI-конвейер;
- расчёты стоимости и КБЖУ выполняются детерминированным кодом backend;
- PostgreSQL доступен только backend;
- ключ GigaChat хранится только на сервере и не попадает в мобильный клиент.
