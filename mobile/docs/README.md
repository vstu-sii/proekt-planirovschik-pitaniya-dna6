# UI-прототип

Прототип ключевых экранов создан агентом как Expo/React Native код и проверен Delivery
Engineer. Макеты Figma и Miro не используются.

## Экраны

1. `01-profile.png` — параметры пользователя, цель, бюджет и время готовки;
2. `02-pantry.png` — домашние запасы и пищевые ограничения;
3. `03-plan.png` — дневной рацион, КБЖУ и контроль бюджета.

Исходный код находится в [`../App.tsx`](../App.tsx). Данные на экранах являются тестовыми;
подключение к API выполняется в лабораторной работе №3.
Векторные исходники кадров (`profile.svg`, `pantry.svg`, `plan.svg`) лежат рядом со
скриншотами, поэтому визуальные материалы также воспроизводимы как код.

Для просмотра в браузере:

```bash
cd mobile
npm ci
npm run web
```
