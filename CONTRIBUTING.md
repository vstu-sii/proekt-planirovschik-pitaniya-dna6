# Правила работы с репозиторием

## Ветки

- `main` — защищённая стабильная ветка.
- Рабочая ветка создаётся от актуального `main`.
- Формат ветки: `lab<номер>-<роль>-<задача>`, например `lab1-delivery-initiation`.
- Прямые коммиты в `main` не допускаются.

## Pull Request

1. Обновить рабочую ветку относительно `main`.
2. Запустить локальные проверки.
3. Открыть Pull Request в `main` и заполнить шаблон.
4. Получить минимум одно одобрение участника команды.
5. Дождаться успешного выполнения всех CI-проверок.
6. Выполнить squash merge.

В настройках GitHub для `main` следует включить обязательный Pull Request, одно одобрение и
обязательные проверки `Backend lint and test`, `Mobile lint, format and export` и
`Container build`.
